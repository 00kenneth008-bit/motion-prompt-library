# Combined 3D Scroll — 3D + 滚动组合：翻转卡片随滚动揭示

人格：Premium｜情绪：惊喜｜适用：产品展示页、作品集、宣传长页

## 为什么是高级（比基础提示词难在哪）

单条基础提示词只做一种效果（要么 3D 翻转，要么滚动揭示，要么视差），这条把三种机制叠在同一张卡片上、按同一滚动事件排时序：卡片随滚动进入视口时先做视差位移 + 淡入上移揭示（第 1、2 个机制）→ 揭示完成后卡片才接受翻转，点击后绕 Y 轴翻转 180° 露出背面（第 3 个机制）。三者必须分先后——没揭示完就翻转会穿帮，翻转时视差不能再推卡片；还要保证翻转全程背面不可见、翻转后内容可读。任何一层时序错位，卡片都会闪一下或翻到一半卡住。

## 提示词（复制给 AI）

```
你是一名重视可访问性的前端工程师。请用原生 HTML、CSS 和 JavaScript 制作一个中文示例产品的响应式展示长页，核心是 3D 翻转卡片随滚动揭示：视差 + 翻转 + 渐入三合一。

目标：让访客向下滚动时看到三张示例卡片依次从下方浮现，点任意一张翻到背面看到更多说明，最后在页末找到“查看全部”操作。

页面结构：顶部导航（Logo + 3 个链接）、首屏（小标题 + 主标题 + 副标题）、卡片区（标题 + 3 张 3D 翻转卡片，每张正面：小标题 + 一段话 + “点击翻转”提示，背面：标题 + 3 条要点 + 一个小按钮）、页末 CTA（标题 + 一个主按钮）、页脚。
时序总表：卡片进入视口 20% 时先做揭示（淡入上移，300ms）→ 揭示完成后才可翻转 → 点击卡片绕 Y 轴翻转 180°（500ms），再点翻回；滚动过程中卡片另有 0.08× 的轻微视差位移。

内容要求：主标题不超过 12 个字；每张卡片正面一段话不超过 30 个字；背面要点 3 条，每条不超过 10 个字；全部用“示例产品 / 示例卡片”等明显占位写法；不要编造用户数量、奖项、统计数据；未知数据用明确占位。

视觉规范：深色背景（近黑），单一浅色强调（米白）；标题中等字重，字间距宽松；圆角 12px；最大内容宽度 1200px；无渐变和装饰性光晕。
人格 Premium，全篇只用一种人格。标志性缓动 ease-out-expo（cubic-bezier(0.16,1,0.3,1)），超调 15–30%（只体现在揭示的收尾速度上，翻转本身不超调、不穿帮）。
主情绪惊喜：揭示用径向向外展开的感觉，卡片从下方浮现、150–300ms 起步、500ms 内完成；翻转 500ms、揭示 300ms。
单次运动不超屏幕 1/3；每时每刻只有一个主角，其他元素暗到 40–60%。

交互要求：
- 滚动揭示：卡片进入视口 20% 时淡入上移（透明度 0→1 + 上移 20px，300ms，cubic-bezier(0.16,1,0.3,1)），三张卡间隔 120ms，第三张晚 200ms；用 IntersectionObserver（threshold: 0.2）触发，只触发一次；未揭示的卡片不可点击翻转。
- 视差：滚动时卡片区整体按滚动量的 0.08 倍做 translateY 位移（只动 transform），用 requestAnimationFrame 节流；揭示动画进行中不叠加视差，翻转进行中视差暂停。
- 3D 翻转：点击已揭示的卡片，卡片内层绕 Y 轴翻转 180°（500ms，cubic-bezier(0.16,1,0.3,1)），透视 perspective: 1000px，正反两面都设 backface-visibility: hidden；翻转中途背面不可见；再点一次翻回正面；翻转是 button 语义（卡片用 button 元素或 role="button"，可用键盘操作，aria-pressed 标明正反面）。
- 按钮 hover 时透明度 0.85，300ms；无缩放、无弹跳。
- 次要层：每张卡片下方的阴影（flip-shadow）比卡片晚 100ms 出现，翻转时阴影同步轻微放大（幅度只有卡片翻转的 30%），从不抢主角。
- 环境层：首屏背景有 2 个极淡的漂浮图形（ambient），缓慢上下浮动（ease-in-out 往返循环，6000ms，幅度 10–20%），从不抢注意力；不用线性缓动做空间移动。
- 每时每刻只有一个主角，其他元素暗到 40–60%。

技术约束：单文件输出，不引入第三方框架和图片，不使用内联事件；翻转只用 transform（rotateY）+ opacity，不动宽高与阴影。
响应式：390px、768px、1440px 无横向滚动，正文不小于 16px；窄屏时三张卡片改为单列纵向排列，翻转与揭示不变。

验收：代码后列出标题层级、键盘、窄屏和空状态检查结果；动效检查：缓动是不是 (0.16,1,0.3,1)、翻转是不是 180°、正反面 backface-visibility 是不是 hidden、未揭示的卡片点按是不是无反应、揭示与翻转是不是分先后、单次运动不超 1/3、次要层和环境层是否齐全；无法判断的项目标注“需浏览器实测”。
```
