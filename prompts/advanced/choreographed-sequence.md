# Choreographed Sequence — 多段编排：首屏入场 → 滚动揭示 → 区块切换

人格：Premium｜情绪：优雅｜适用：品牌落地页、产品发布长页、故事型介绍页

## 为什么是高级（比基础提示词难在哪）

单条基础提示词只能做一段动效（要么首屏入场，要么滚动揭示，要么标签切换），这条复合了三段机制，并用一条全页主时间线把它们排起来：首屏加载后按 120ms / 240ms / 360ms 依次登场（第 1 段）→ 滚动到特性区块时三张卡片再按 120ms 间隔依次揭示（第 2 段）→ 展示区块点标签切换面板，旧面板先淡出、新面板再淡入上移（第 3 段）。三段共用同一套 Premium 缓动与时长档，任何一段抢拍或断档，整页时序就乱了；还要保证三段交接时每时每刻只有一个主角。

## 提示词（复制给 AI）

```
你是一名重视可访问性的前端工程师。请用原生 HTML、CSS 和 JavaScript 制作一个中文示例产品的响应式品牌长页，核心是全页三段时序编排：首屏入场 → 滚动揭示 → 区块切换。

目标：让访客按固定顺序理解示例产品——先看到主张，再看到三个特性，最后在展示区块里切换查看三类内容，页末找到“了解更多”操作。

页面结构：顶部导航（Logo + 3 个链接 + 一个按钮）、首屏（小标题 + 主标题 + 副标题 + 两个按钮 + 底部 3 点时间线指示）、特性区块（标题 + 3 张特性卡，每张：小标题 + 一段话）、展示区块（标题 + 3 个标签按钮 + 3 个切换面板，每个面板：标题 + 一段话 + 3 条要点）、页末 CTA（标题 + 一个主按钮）、页脚。
时序总表：首屏加载后 0–900ms 内按 120ms / 240ms / 360ms 依次登场；滚动到特性区块时卡片按 120ms 间隔依次揭示；展示区块点标签时旧面板 400ms 淡出、新面板 500ms 淡入上移。

内容要求：主标题不超过 12 个字；每张特性卡一段话不超过 30 个字；每个展示面板要点 3 条，每条不超过 10 个字；全部用“示例产品 / 示例公司”等明显占位写法；不要编造用户数量、奖项、统计数据；未知数据用明确占位。

视觉规范：浅色背景（近白），深灰文字，单一深蓝强调；标题大字重，圆角 12px；最大内容宽度 1200px；无渐变和装饰性光晕。
人格 Premium，全篇只用一种人格。标志性缓动 cubic-bezier(0.4,0,0.2,1)，超调 0%。
主情绪优雅：所有运动都用慢、受控的长弧线，400–700ms；首屏入场 600ms、区块揭示 500ms、面板切换 400ms。
单次运动不超屏幕 1/3；每时每刻只有一个主角，其他元素暗到 40–60%。

交互要求：
- 首屏时间线入场：页面加载后小标题、主标题、副标题、按钮组按 120ms / 240ms / 360ms 的延迟依次淡入上移（透明度 0→1 + 上移 24px，600ms，cubic-bezier(0.4,0,0.2,1)）；时间线指示的 3 个点随对应元素亮起。
- 滚动揭示：特性区块进入视口 20% 时，三张卡片依次淡入上移（透明度 0→1 + 上移 20px，500ms，cubic-bezier(0.4,0,0.2,1)），间隔 120ms；用 IntersectionObserver（threshold: 0.2）触发，只触发一次。
- 区块切换：点击展示区块的标签按钮（button 元素，aria-pressed），当前面板先淡出（透明度 1→0，400ms），新面板再淡入上移（透明度 0→1 + 上移 12px，500ms）；同一时间只显示一个面板；当前标签按钮用强调色下划线标明。
- 按钮 hover 时透明度 0.85，400ms；无缩放、无弹跳。
- 次要层：每个区块的小标题 caption（seq-caption）比主标题晚 100ms 出现，上移幅度只有主标题的 30%（8px），从不抢主角。
- 环境层：首屏背景有 2 个极淡的漂浮图形（ambient），缓慢上下浮动（ease-in-out 往返循环，6000ms，幅度 10–20%），从不抢注意力；不用线性缓动做空间移动。
- 每时每刻只有一个主角，其他元素暗到 40–60%。

技术约束：单文件输出，不引入第三方框架和图片，不使用内联事件；滚动揭示用 IntersectionObserver，不用 scroll 事件直接改样式。
响应式：390px、768px、1440px 无横向滚动，正文不小于 16px；窄屏时三张特性卡改为单列，标签按钮可横向滚动但页面本身不横向滚动。

验收：代码后列出标题层级、键盘、窄屏和空状态检查结果；动效检查：缓动是不是 (0.4,0,0.2,1)、超调是不是 0%、三段时序是不是按 120ms / 240ms / 360ms 与 120ms 间隔排布、单次运动不超 1/3、次要层和环境层是否齐全、切换时是不是同一时间只显示一个面板；无法判断的项目标注“需浏览器实测”。
```
