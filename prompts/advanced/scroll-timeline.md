# Scroll Timeline — 滚动时间线：进度条 + 视差 + 透明度 + 缩放联动

人格：Corporate｜情绪：平静｜适用：公司历程页、产品路线图、年度回顾长页

## 为什么是高级（比基础提示词难在哪）

单条基础提示词只做一种滚动效果（要么进度条，要么视差，要么揭示），这条复合了四种机制，并用同一个滚动进度值同时驱动它们：顶部进度条 scaleX 跟随滚动进度（第 1 个机制）→ 背景层与中间层按 0.2× / 0.5× 做视差（第 2 个机制）→ 每个里程碑节点按进度依次点亮，透明度 0.4→1（第 3 个机制）→ 节点标记按进度从 0.6 缩放到 1（第 4 个机制）。四个机制必须由同一个进度值算出、同一帧更新，任何一个滞后或各算各的，联动感就断了；还要保证滚动停止时四处同时停稳。

## 提示词（复制给 AI）

```
你是一名重视可访问性的前端工程师。请用原生 HTML、CSS 和 JavaScript 制作一个中文示例公司的响应式滚动时间线长页，核心是一个滚动进度同时驱动进度条、视差、透明度、缩放四种变化。

目标：让访客向下滚动时，沿着时间线读完示例公司的四个阶段，顶部的进度条随时告诉他读到了哪里，最后在页末找到“联系我们”操作。

页面结构：顶部固定进度条（细条 + 进度填充 + 百分比文字）、首屏（小标题 + 主标题 + 一句话说明）、时间线（4 个里程碑节点，每个节点：年份占位 + 标题 + 一段话 + 一个标记圆点）、页末 CTA（标题 + 一个主按钮）、页脚。
联动总表：滚动进度 p（0→1）同时驱动——进度条填充 scaleX = p；背景层 translateY = 滚动量 × 0.2，中间层 × 0.5；里程碑节点在进入视口 20% 时点亮，透明度 0.4→1；节点标记按本节点进度从 scale(0.6) 放到 scale(1)。

内容要求：主标题不超过 12 个字；每个里程碑一段话不超过 30 个字；年份、数据全部用明确占位（如“20XX 年”“示例数据”）；不要编造真实年份、融资额、用户数；未知数据用明确占位。

视觉规范：浅色背景（近白），深灰文字，单一深蓝强调；标题中等字重；圆角 12px；最大内容宽度 1000px；无渐变和装饰性光晕。
人格 Corporate，全篇只用一种人格。标志性缓动 cubic-bezier(0.2,0,0,1)，超调 0–3%。
主情绪平静：所有变化都轻柔、受控，200–400ms；节点点亮 400ms、标记缩放 300ms、进度条跟随 200ms；不用弹跳、不用超调。
单次运动不超屏幕 1/3；每时每刻只有一个主角，其他元素暗到 40–60%。

交互要求：
- 滚动进度驱动：监听滚动，用 requestAnimationFrame 节流，每帧算一次进度 p = 已滚动距离 / 可滚动总距离；进度条填充用 transform: scaleX(p)（只动 transform），百分比文字同步更新；滚动停止时四处同时停稳，不回弹。
- 视差联动：背景层与中间层随滚动用 translateY 移动，速度分别是滚动量的 0.2 倍和 0.5 倍（只动 transform）；两层速度不同才有纵深。
- 节点点亮：每个里程碑进入视口 20% 时点亮（透明度 0.4→1 + 上移 16px，400ms，cubic-bezier(0.2,0,0,1)），间隔 80ms；用 IntersectionObserver（threshold: 0.2）触发，只触发一次；未点亮的节点保持 40% 透明度。
- 标记缩放：节点点亮时标记圆点从 scale(0.6) 放到 scale(1)，300ms，cubic-bezier(0.2,0,0,1)；点亮后标记保持强调色。
- 按钮 hover 时透明度 0.85，300ms；无缩放、无弹跳。
- 次要层：每个节点的年份小字（tl-caption）比节点标题晚 160ms 出现，上移幅度只有主标题的 30%（5px），从不抢主角。
- 环境层：首屏背景有极淡的圆点阵列（ambient），透明度在 0.9–1 之间缓慢呼吸（ease-in-out 往返循环，4000ms），从不抢注意力；不用线性缓动做空间移动。
- 每时每刻只有一个主角，其他元素暗到 40–60%。

技术约束：单文件输出，不引入第三方框架和图片，不使用内联事件；滚动监听用 requestAnimationFrame 节流，不用 scroll 事件直接改样式。
响应式：390px、768px、1440px 无横向滚动，正文不小于 16px；窄屏时时间线改为单列、标记圆点仍在左侧，进度条保持顶部固定。

验收：代码后列出标题层级、键盘、窄屏和空状态检查结果；动效检查：缓动是不是 (0.2,0,0,1)、超调是不是 0–3%、滚动到 45% 时进度条 scaleX 是不是约 0.45、视差两层速度是不是 0.2×/0.5×、节点点亮与标记缩放是不是同步、单次运动不超 1/3、次要层和环境层是否齐全；无法判断的项目标注“需浏览器实测”。
```
