# Staggered Grid — 交错网格编排：波浪式入场 + 鼠标跟随高亮

人格：Energetic｜情绪：惊喜｜适用：活动页、作品墙、功能总览页

## 为什么是高级（比基础提示词难在哪）

单条基础提示词只做一种网格效果（要么一起淡入，要么 hover 放大），这条复合了三种机制，并用网格位置算时序：8 张卡片按“列”分组波浪式依次入场——同一列的卡片同时动，相邻列晚 60ms，整面网格像波浪一样从左向右推过去（第 1 个机制）→ 入场完成后鼠标移到哪张卡片，哪张立刻亮起、其余暗下去（第 2 个机制）→ 一个圆形高亮光斑跟随鼠标在网格内平滑移动（第 3 个机制）。波浪时序要按列算、不能按 DOM 顺序一刀切；高亮与光斑必须跟随鼠标实时走、不能等入场动画跑完；三者共用 Energetic 的快节奏，任何一段拖慢，波浪感就散了。

## 提示词（复制给 AI）

```
你是一名重视可访问性的前端工程师。请用原生 HTML、CSS 和 JavaScript 制作一个中文示例活动的响应式网格页，核心是交错网格编排：卡片波浪式入场 + 鼠标跟随高亮。

目标：让访客一眼看到 8 张示例卡片像波浪一样依次浮现，鼠标移到哪张、哪张就亮起来，最后在页末找到“立即参与”操作。

页面结构：顶部导航（Logo + 3 个链接）、首屏（小标题 + 主标题 + 一句话说明）、网格区（标题 + 8 张卡片排成 4 列 × 2 行，每张：编号占位 + 小标题 + 一句话）、页末 CTA（标题 + 一个主按钮）、页脚。
时序总表：网格进入视口 15% 时开始波浪入场——第 1 列 0ms、第 2 列 60ms、第 3 列 120ms、第 4 列 180ms，同一列两张卡片同时动；每张卡片入场 250ms；鼠标进入网格后高亮 200ms 内跟上，光斑 150ms 内平滑跟到鼠标位置。

内容要求：主标题不超过 12 个字；每张卡片一句话不超过 15 个字；编号、数据全部用明确占位（如“示例 01”）；不要编造用户数量、奖项、统计数据；未知数据用明确占位。

视觉规范：深色背景（近黑），单一亮色强调（亮黄）；标题大字重；圆角 12px；最大内容宽度 1200px；无渐变和装饰性光晕。
人格 Energetic，全篇只用一种人格。标志性缓动 ease-out-expo（cubic-bezier(0.16,1,0.3,1)），超调 15–30%。
主情绪惊喜：入场用径向向外展开的感觉，卡片从下方弹现，150–300ms；卡片入场 250ms、卡片高亮 200ms、光斑跟随 150ms。
单次运动不超屏幕 1/3；每时每刻只有一个主角，其他元素暗到 40–60%。

交互要求：
- 波浪式入场：网格进入视口 15% 时，8 张卡片按列分组依次淡入上移（透明度 0→1 + 上移 20px，250ms，cubic-bezier(0.16,1,0.3,1)），第 1 列延迟 0ms、第 2 列 60ms、第 3 列 120ms、第 4 列 180ms；用 IntersectionObserver（threshold: 0.15）触发，只触发一次；延迟按列算，不按 DOM 顺序。
- 鼠标跟随高亮：鼠标进入网格后，鼠标所在的卡片立刻亮起（边框强调色 + 透明度 1，200ms，cubic-bezier(0.16,1,0.3,1)），其余卡片暗到 50%；鼠标移出网格后全部恢复；同一时间只高亮一张卡片。
- 光斑跟随：一个圆形高亮光斑（spotlight，直径 120px，强调色，透明度 0.15）在网格内跟随鼠标移动，用 transform 平滑跟随（150ms，cubic-bezier(0.16,1,0.3,1)），只动 transform + opacity；鼠标移出网格后光斑淡出。
- 卡片 hover 时上移 4px，200ms；无弹跳出格、无缩放超 1.05。
- 次要层：每张卡片内的小标题（grid-caption）比卡片主体晚 100ms 出现，上移幅度只有卡片的 30%（6px），从不抢主角。
- 环境层：首屏背景有 2 个极淡的漂浮图形（ambient），缓慢上下浮动（ease-in-out 往返循环，5000ms，幅度 10–20%），从不抢注意力；不用线性缓动做空间移动。
- 每时每刻只有一个主角，其他元素暗到 40–60%。

技术约束：单文件输出，不引入第三方框架和图片，不使用内联事件；波浪延迟按列分组写在 CSS 类里（stagger-0 到 stagger-3），不用 JS 逐个算延迟。
响应式：390px、768px、1440px 无横向滚动，正文不小于 16px；窄屏时网格改为单列，波浪入场改为按行依次（每行晚 60ms），光斑跟随保留但直径减半。

验收：代码后列出标题层级、键盘、窄屏和空状态检查结果；动效检查：缓动是不是 (0.16,1,0.3,1)、波浪延迟是不是按列 0ms / 60ms / 120ms / 180ms、同一时间是不是只高亮一张卡片、光斑是不是跟随鼠标移动、单次运动不超 1/3、次要层和环境层是否齐全；无法判断的项目标注“需浏览器实测”。
```
