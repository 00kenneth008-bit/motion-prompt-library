# Physics Motion — 物理感动效：弹簧回弹 + 惯性拖拽 + 动量滚动

人格：Playful｜情绪：喜悦｜适用：轻松产品页、活动页、儿童与创意类页面

## 为什么是高级（比基础提示词难在哪）

单条基础提示词只做一段写死的 CSS 过渡（时长与缓动固定），这条复合了三种真实物理机制，全部用逐帧积分算出来、不是写死的过渡：可拖拽卡片松手后按弹簧方程回弹（刚度 stiffness、阻尼 damping、质量都要给参数，第 1 个机制）→ 横向内容条拖动后按松手速度做惯性滑行、逐渐减速（第 2 个机制）→ 弹簧按钮点击后按同一组弹簧参数做超调回弹（第 3 个机制）。三个机制共用同一套弹簧参数，拖得越远回弹越明显、松手越快滑得越远；写死过渡做不出“力度决定结果”的手感，参数给错（刚度过大抖动、阻尼过小来回晃）一眼就能看出来。

## 提示词（复制给 AI）

```
你是一名重视可访问性的前端工程师。请用原生 HTML、CSS 和 JavaScript 制作一个中文示例产品的响应式轻松页面，核心是真实物理感动效：弹簧回弹、惯性拖拽、动量滚动。

目标：让访客动手拖一拖、点一点就感受到示例产品的轻松好玩，最后在页末找到“开始体验”操作。

页面结构：顶部导航（Logo + 3 个链接）、首屏（主标题 + 副标题 + 一个弹簧按钮）、可拖拽卡片区（标题 + 一张可拖动的示例卡片 + 一句“拖动我，松手看回弹”提示）、动量内容条（标题 + 一条可横向拖动的卡片条，5 张小卡片）、页末 CTA（标题 + 一个主按钮）、页脚。
物理参数总表：弹簧刚度 stiffness = 180，阻尼 damping = 14，质量 mass = 1；卡片回弹与按钮超调共用这组参数；内容条惯性滑行每帧速度 × 0.95 衰减，速度小于 0.5px/帧时停稳。

内容要求：主标题不超过 10 个字；每张小卡片一句话不超过 10 个字；全部用“示例产品 / 示例卡片”等明显占位写法；不要编造用户数量、奖项、统计数据；未知数据用明确占位。

视觉规范：浅色背景（暖黄到白的柔和配色），单一亮色强调（橙色）；标题大字重，圆角 16px；最大内容宽度 1200px；无渐变和装饰性光晕。
人格 Playful，全篇只用一种人格。标志性缓动 ease-out-back（cubic-bezier(0.68,-0.55,0.27,1.55)），超调 10–20%。
主情绪喜悦：元素入场用弹跳、弧线路径，向上，200–400ms；卡片入场 300ms、内容条卡片 250ms、按钮反馈 200ms。
单次运动不超屏幕 1/3；每时每刻只有一个主角，其他元素暗到 40–60%。

交互要求：
- 弹簧回弹：按住示例卡片可自由拖动（pointer 事件，拖动时卡片跟随手指，translate 跟随指针位置，只动 transform）；松手时记录松手速度，用 requestAnimationFrame 做弹簧积分（加速度 = -stiffness × 位移 - damping × 速度，质量为 1），卡片带速度回弹到原点，可有一次轻微超调（不超过原位移的 20%），最终停稳在原点。
- 惯性拖拽与动量滚动：横向内容条可按住拖动，拖动时条跟随手指；松手后按松手速度继续滑行，每帧速度 × 0.95 衰减，速度小于 0.5px/帧时停稳；滑到两端时不再继续滑出边界。
- 弹簧按钮：点击弹簧按钮，按钮按同一组弹簧参数（stiffness = 180，damping = 14）做一次超调回弹（先放大到 1.1 再回弹到 1，超调 10–20%），用 requestAnimationFrame 逐帧算，不用写死的 CSS 过渡冒充弹簧。
- 入场：卡片与内容条小卡片进入视口时弹入（向上 16px + 透明度 0→1，300ms，ease-out-back，超调 15%），间隔 80ms；内容条小卡片间隔 160ms。
- 次要层：卡片下方的阴影（spring-shadow）跟随卡片位移，移动幅度只有卡片的 40%，卡片回弹时阴影同步回弹，从不抢主角。
- 环境层：首屏背景有 2 个漂浮圆点（ambient），缓慢上下浮动（ease-in-out 往返循环，5000ms，幅度 10–20%），从不抢注意力；不用线性缓动做空间移动。
- 每时每刻只有一个主角，其他元素暗到 40–60%。

技术约束：单文件输出，不引入第三方框架和图片，不使用内联事件；物理动画全部用 requestAnimationFrame 逐帧积分，弹簧参数写成具名常量（stiffness、damping），不写死在魔法数字里。
响应式：390px、768px、1440px 无横向滚动，正文不小于 16px；窄屏时内容条仍可横向拖动、页面本身不横向滚动。

验收：代码后列出标题层级、键盘、窄屏和空状态检查结果；动效检查：缓动是不是 ease-out-back、超调在 10–20% 内、弹簧参数是不是 stiffness = 180 / damping = 14、松手后卡片是不是回到原点且只超调一次、松手后内容条是不是继续滑行再停稳、单次运动不超 1/3、次要层和环境层是否齐全；无法判断的项目标注“需浏览器实测”。
```
