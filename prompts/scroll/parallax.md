# Parallax — 视差滚动，背景比前景慢

人格：Playful｜情绪：喜悦｜适用：儿童活动、夏令营、轻松长页

## 提示词（复制给 AI）

```
你是一名重视可访问性的前端工程师。请用原生 HTML、CSS 和 JavaScript 制作一个中文儿童夏令营的响应式长页，核心是三层视差滚动。

目标：让向下滚动的家长和孩子感受到夏令营的快乐氛围，并在页末找到“立即报名”操作。

页面结构：顶部导航（Logo + 3 个链接 + 报名按钮）、首屏（主标题、副标题、一个主按钮、视差场景）、3 个活动区块（每个区块：标题 + 一段话 + 一张示意图）、页末 CTA（标题 + 一个主按钮）、页脚。
视差场景三层：背景云朵层、中间山丘层、前景草地 + 内容层。

内容要求：主标题不超过 10 个字；每个区块标题不超过 10 个字；不要编造用户数量、奖项；未知数据用明确占位。

视觉规范：浅色背景（天蓝到草绿的柔和配色），单一亮色强调（橙色）；标题大字重，圆角 16px；最大内容宽度 1200px；无渐变和装饰性光晕。
人格 Playful，全篇只用一种人格。标志性缓动 ease-out-back，超调 10–20%。
主情绪喜悦：元素入场用弹跳、弧线路径，向上，200–400ms。
视差速度：滚动时背景云朵层移动滚动量的 0.3 倍，中间山丘层 0.6 倍，前景内容层 1 倍；三层速度不同才有纵深。

交互要求：
- 视差滚动：滚动时三层按 0.3× / 0.6× / 1× 的速度用 translateY 移动（只动 transform），用 requestAnimationFrame 节流；滚动停止时各层停稳，不回弹。
- 区块入场：每个区块进入视口 20% 时，标题和示意图弹入（300ms，ease-out-back，超调 15%，向上 16px + 透明度 0→1），间隔 80ms。
- 按钮 hover 时放大 1.05，300ms ease-out-back；点击时缩小 0.97。
- 次要层：漂浮气球 2 个，随滚动轻微上下浮动，幅度为主视觉的 30–50%，比主层晚 50–100ms。
- 环境层：云朵缓慢横移（ease-in-out 往返循环，8000ms），从不抢注意力；不用线性缓动做空间移动。
- 每时每刻只有一个主角，其他元素暗到 40–60%。

技术约束：单文件输出，不引入第三方框架和图片，不使用内联事件；滚动监听用 requestAnimationFrame 节流，不用 scroll 事件直接改样式。
响应式：390px、768px、1440px 无横向滚动，正文不小于 16px；窄屏时视差三层保留，但移动幅度减半。

验收：代码后列出标题层级、键盘、窄屏和空状态检查结果；动效检查：缓动是不是 ease-out-back、超调在 10–20% 内、三层速度是不是 0.3×/0.6×/1×、单次运动不超 1/3、次要层和环境层是否齐全；无法判断的项目标注“需浏览器实测”。
```
