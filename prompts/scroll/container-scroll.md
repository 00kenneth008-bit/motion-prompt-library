# Container Scroll — 滚动触发的分段揭示

人格：Corporate｜情绪：平静｜适用：SaaS 长落地页、仪表盘、后台

## 提示词（复制给 AI）

```
你是一名重视可访问性的前端工程师。请用原生 HTML、CSS 和 JavaScript 制作一个中文 SaaS 产品的响应式长落地页，核心是滚动触发的分段揭示。

目标：让向下滚动的用户每到一个区块都清楚看到一个卖点，并在页末找到“开始使用”操作。

页面结构：顶部导航（Logo + 4 个链接 + 登录/注册）、首屏（主标题、副标题、一个主按钮）、4 个内容区块（每个区块：小标题 + 标题 + 一段话 + 一张示意图，左右交错排列）、页末 CTA（标题 + 一个主按钮）、页脚。

内容要求：主标题不超过 12 个字；每个区块标题不超过 10 个字；不要编造客户 Logo、奖项；未知数据用明确占位。

视觉规范：白色或浅灰背景，单一蓝色强调；标题中等字重；圆角 8px；最大内容宽度 1200px；无渐变和装饰性光晕。
人格 Corporate，全篇只用一种人格。标志性缓动 cubic-bezier(0.2,0,0,1)，超调 0–3%。
主情绪平静：揭示用平滑、流动的轻柔曲线，200–400ms。
揭示规则：用 IntersectionObserver，区块进入视口 20% 时触发；已揭示的不重复触发。

交互要求：
- 区块揭示：每个区块进入视口 20% 时，标题、段落、示意图依次淡入（透明度 0→1 + 上移 16px，400ms，cubic-bezier(0.2,0,0,1)），间隔 80ms。
- 顶部进度条：页面顶部一条 3px 进度条，随滚动进度用 scaleX（transform，左端为原点）从 0 伸到 1；不用 width 做动画。
- 按钮 hover 时背景色加深 10%，200ms；无缩放、无弹跳。
- 次要层：每个区块内的小标题比标题晚 100ms 出现，幅度为主区块的 30%。
- 环境层：无（Corporate 人格不需要环境层，保持干净）。
- 每时每刻只有一个主角，其他元素暗到 40–60%。

技术约束：单文件输出，不引入第三方框架和图片，不使用内联事件；滚动监听用 IntersectionObserver + requestAnimationFrame，不用 scroll 事件直接改样式。
响应式：390px、768px、1440px 无横向滚动，正文不小于 16px；窄屏时区块改为纵向排列，示意图在文字下方。

验收：代码后列出标题层级、键盘、窄屏和空状态检查结果；动效检查：缓动是不是 (0.2,0,0,1)、超调在 0–3% 内、时长在 200–400ms 内、揭示阈值是不是 20%、进度条是不是 scaleX、次要层是否齐全；无法判断的项目标注“需浏览器实测”。
```
