# Snap Scroll — 全屏滚动吸附分段

人格：Energetic｜情绪：惊喜｜适用：音乐节、活动页、新品发布

## 提示词（复制给 AI）

```
你是一名重视可访问性的前端工程师。请用原生 HTML、CSS 和 JavaScript 制作一个中文音乐节的响应式活动页，核心是全屏滚动吸附分段。

目标：让访问的用户一屏一屏刷完 4 个活动亮点，并在末屏找到“立即抢票”操作。

页面结构：4 个全屏分段（每段：一个大标题 + 一句话 + 一张主视觉 + 一个小按钮），右侧固定圆点导航（4 个点，当前段高亮），每段背景色不同。
分段内容：第一段音乐节名称 + 日期，第二段阵容，第三段场地，第四段票价 + 抢票按钮。

内容要求：每段标题不超过 10 个字；日期、票价用真实数字或明确占位；不要编造参与人数、奖项；未知数据用明确占位。

视觉规范：深色背景，每段一个亮色强调（亮黄、亮红、亮蓝、亮绿轮换）；标题大字重，全大写或加粗；圆角 4px；最大内容宽度 1200px；无渐变和装饰性光晕。
人格 Energetic，全篇只用一种人格。标志性缓动 ease-out-expo，超调 15–30%。
主情绪惊喜：每段进入时标题突然、扩张地径向弹出，150–300ms。
吸附：CSS scroll-snap-type: y mandatory，每段 scroll-snap-align: start；滚动停下时自动吸附到最近一段的顶部。

交互要求：
- 分段进入：每段进入视口时，标题从缩放 0.8 + 透明度 0 弹出（200ms，ease-out-expo，超调 20%），副标题晚 60ms，主视觉晚 120ms。
- 圆点导航：点击圆点平滑滚动到对应分段（scroll-behavior: smooth）；当前段圆点放大 1.3 并变亮色。
- 段落切换：背景色过渡 250ms ease-out-expo；一次只高亮一段，其他段暗到 40–60%。
- 按钮 hover 时放大 1.08，200ms ease-out-expo；点击时缩小 0.95。
- 次要层：每段一个装饰图形（音符/线条），随标题弹出，幅度为主视觉的 30–50%，比主层晚 50ms。
- 环境层：每段底部一条音浪（5 根竖条，scaleY 循环跳动，ease-in-out，600ms），从不抢注意力。
- 慎用：Energetic 只在 4 个活动分段用，页脚用人格降一级的 Corporate，避免处处都炸。

技术约束：单文件输出，不引入第三方框架和图片，不使用内联事件；吸附用 CSS scroll-snap，不用 JS 模拟滚动。
响应式：390px、768px、1440px 无横向滚动，正文不小于 16px；窄屏时圆点导航移到屏幕底部横排。

验收：代码后列出标题层级、键盘、窄屏和空状态检查结果；动效检查：缓动是不是 ease-out-expo、超调在 15–30% 内、时长在 100–250ms 内、吸附是不是停在段顶、单次运动不超 1/3、次要层和环境层是否齐全；无法判断的项目标注“需浏览器实测”。
```
