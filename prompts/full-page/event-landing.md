# Event Landing — 活动落地页全页：首屏 + 倒计时 + 阵容 + 场地 + 票价 + 页脚

人格：Energetic｜情绪：惊喜｜适用：活动页、发布会、演出/展会预告

## 提示词（复制给 AI）

```
你是一名重视可访问性的前端工程师。请用原生 HTML、CSS 和 JavaScript 制作一个中文活动（示例活动）的响应式落地页全页，核心是六个区块按一条快、有劲、但不乱的动线串成一页。

1. 角色与目标
你是一名重视可访问性的前端工程师，同时是这场活动的现场向导。页面最终要帮助访客在 30 秒内被点燃兴趣、看到倒计时产生紧迫感、认出阵容、找到场地信息，并完成选票操作；动效要快、要醒目，但一次只推一个主角，绝不全页一起炸。

2. 页面类型与结构
这是一个单页活动落地页，按顺序必须包含以下六个区块，一个不少，顺序不换：
- 首屏：活动名（示例活动）+ 主标题（不超过 10 个字）+ 一句话副标题 + 一个主按钮（“立即选票”）+ 活动日期与城市占位行。
- 倒计时区：区块标题 + 倒计时四格（天 / 时 / 分 / 秒），数字每秒更新一次，目标时间用占位写法（如“活动开始前”）。
- 阵容区：区块标题 + 4 张嘉宾卡（每张：编号 + 示例嘉宾名 + 一句话介绍），两列排列。
- 场地：区块标题 + 场地信息三行（示例场馆名 / 示例地址 / 交通占位）+ 一个纯 CSS 示意区（色块占位，不用图片、不用地图）。
- 票价区：区块标题 + 三档票（每档：档名 + 价格占位 + 两条权益 + 一个“选择此档”按钮），点选后下方出现已选提示行。
- 页脚：活动名 + 两列链接（均为示例链接文字）+ 底部一行（示例主办方 + 版权占位年份）。

3. 真实内容与事实边界
活动名、嘉宾名、场馆名、主办方一律用“示例活动”“示例嘉宾一”“示例场馆”“示例主办方”等明显占位写法，不编逼真品牌名和真实人名。日期、地址、票价一律用占位写法（如“示例日期”“¥99 起”）。不要编造已售票数、嘉宾成就、奖项和统计数据；未知数据用明确占位。倒计时目标时间在代码里写成占位（自页面打开起 26 天后），不写真实活动日期。

4. 视觉规则
深色背景（近黑），单一亮色强调（亮黄），标题大字重；圆角 16px；最大内容宽度 1200px；无渐变和装饰性光晕。
人格 Energetic，全篇只用一种人格。标志性缓动 ease-out-expo（cubic-bezier(0.16,1,0.3,1)），超调 15–30%。
主情绪惊喜：元素入场用径向向外、快而有冲劲的展开，100–250ms；倒计时数字变化只换文字，不做空间位移动画。

5. 交互与状态
- 全页串联（这是整页提示词的关键）：六个区块共用同一个人格 Energetic 和同一套缓动/时长档（cubic-bezier(0.16,1,0.3,1)，100–250ms），不许某个区块换人格、换缓动。区块之间的衔接用“收尾—开场”过渡：上一区块的最后一组元素完全入场后，下一区块的首元素才开始入场（IntersectionObserver threshold 0.2 触发，区块内元素依次延迟 60ms 出现）；倒计时区是全页唯一的常动区，其他区块入场时倒计时只换数字、不参与入场动画，避免两个主角同时动。
- 首屏入场：活动名、标题、副标题、按钮、日期行依次弹出（透明度 0→1 + 上移 16px + 缩放 0.96→1，200ms，ease-out-expo，间隔 60ms）。
- 倒计时：每秒更新一次（setInterval 1000ms），天/时/分/秒四格只换文字；秒格变化时数字透明度闪一下（0.6→1，150ms），不做位移、不做缩放。
- 阵容卡入场：进入视口 20% 时依次弹出（200ms，间隔 60ms）；嘉宾编号徽标（次要层）比卡片晚 80ms 出现，幅度为主卡片的 30%（上移 6px 对 16px）；悬停时卡片上移 4px（200ms），无弹跳放大。
- 票价点选：点击“选择此档”，该档边框变强调色、按钮文字变为“已选择”（aria-pressed 同步更新），下方已选提示行淡入（200ms）；一次只选中一档，选新档时旧档自动取消。
- 页脚入场：滚动到底部时链接列依次淡入（200ms，间隔 60ms）。
- 环境层：首屏背景有两个色块缓慢漂移（translate 往返，6000ms ease-in-out），幅度小、从不抢注意力；不用线性缓动做空间移动。
- 每时每刻只有一个主角，其他元素暗到 40–60%。

6. 技术约束
单文件 index.html，内联 CSS + JS，无构建步骤，无本地素材，不引入第三方框架和图片，不使用内联事件。倒计时用 setInterval 每秒更新，目标时间取页面打开时刻加 26 天；票价点选用 button 元素（aria-pressed），可用键盘操作；滚动监听用 IntersectionObserver，不用 scroll 事件直接改样式。

7. 验收
代码后列出标题层级、键盘、窄屏和空状态检查结果；动效检查：缓动是不是 ease-out-expo（cubic-bezier(0.16,1,0.3,1)）、超调在 15–30% 内、时长在 100–250ms 内、单次运动不超 1/3、次要层和环境层是否齐全；全页时序一致性检查：六个区块是否共用同一个人格和同一套缓动/时长档、入场顺序是否按区块顺序依次触发、倒计时走字时有没有其他区块在做入场动画、点选票档时已选提示是否只出现一条；无法判断的项目标注“需浏览器实测”。
```
