# Brand Landing — 品牌落地页全页：首屏 + 故事 + 产品 + 评价 + 页脚

人格：Premium｜情绪：优雅｜适用：品牌官网、宣传落地页

## 提示词（复制给 AI）

```
你是一名重视可访问性的前端工程师。请用原生 HTML、CSS 和 JavaScript 制作一个中文品牌（示例品牌）的响应式落地页全页，核心是五个区块按一条优雅、克制的动线串成一页。

1. 角色与目标
你是一名重视可访问性的前端工程师，同时是这个品牌的视觉向导。页面最终要帮助第一次来的访客感受到品牌的气质、读懂品牌故事、看到代表产品、听到他人的评价，并在页末找到“了解更多”操作；动效本身要像品牌的一部分，慢、稳、不催促。

2. 页面类型与结构
这是一个单页品牌落地页，按顺序必须包含以下五个区块，一个不少，顺序不换：
- 首屏：品牌名（示例品牌）+ 主标题（不超过 12 个字）+ 一句话副标题 + 一个主按钮（“了解更多”）+ 一张示意区（纯 CSS 色块占位，不用图片）。
- 故事区：区块标题 + 品牌故事三段（每段：小标题 + 一句话），按时间顺序排成三步。
- 产品区：区块标题 + 3 张产品卡（每张：示意区 + 产品名 + 一句话说明 + 一个文字链接），中间一张为代表产品（边框强调、静态抬升 8px）。
- 评价区：区块标题 + 一条评价轮播（评价文字 + 示例评价人 + 上一条/下一条按钮），共 3 条评价，一次只显示一条。
- 页脚：品牌名 + 两列链接（均为示例链接文字）+ 底部一行（示例品牌 + 版权占位年份）。

3. 真实内容与事实边界
品牌名、产品名、人名一律用“示例品牌”“示例产品”“示例评价人”等明显占位写法，不编逼真品牌名和真实人名。不要编造客户数量、奖项、销量、统计数据和服务承诺；未知数据用明确占位。评价文字写通用好评句式，不编具体使用场景和数字。

4. 视觉规则
浅色背景（米白底 + 白色卡片），单一深色强调（深灰），标题中等字重、字间距宽松；圆角 12px；最大内容宽度 1200px；无渐变和装饰性光晕。
人格 Premium，全篇只用一种人格。标志性缓动 cubic-bezier(0.4,0,0.2,1)，超调 0%。
主情绪优雅：所有入场与切换都用慢、受控的长弧线，400–700ms，不弹跳、不加速。

5. 交互与状态
- 全页串联（这是整页提示词的关键）：五个区块共用同一个人格 Premium 和同一套缓动/时长档（cubic-bezier(0.4,0,0.2,1)，400–700ms），不许某个区块换人格、换缓动。区块之间的衔接用“收尾—开场”过渡：上一区块的最后一组元素完全入场后，下一区块的首元素才开始入场（IntersectionObserver threshold 0.2 触发，区块内元素依次延迟 120ms 出现）；区块之间不做整屏跳切、不做视差、不做翻页，衔接只靠统一的上移淡入 + 120ms stagger，保持一根动线。
- 首屏入场：品牌名、标题、副标题、按钮、示意区依次淡入上移（透明度 0→1 + 上移 20px，600ms，间隔 120ms）。
- 故事区入场：三步依次淡入上移（600ms，间隔 120ms）；每步的年份标记（次要层）比正文晚 150ms 出现，幅度为主内容的 30%。
- 产品卡入场：三张卡依次淡入上移（600ms，间隔 120ms）；代表产品静态抬升 8px（不做动画），边框用强调色；卡片示意区（次要层）悬停时放大 1.03（500ms），卡片本身不上移、不缩放。
- 评价轮播：点击上一条/下一条，当前评价淡出上移 12px（400ms），新评价淡入（400ms）；按钮是 button 元素，可用键盘操作；轮播不自动播放，不抢注意力。
- 页脚入场：滚动到底部时链接列依次淡入（500ms，间隔 120ms）。
- 环境层：首屏背景有极轻微的光晕呼吸（透明度 0.97–1 循环，3000ms ease-in-out），从不抢注意力。
- 每时每刻只有一个主角，其他元素暗到 40–60%。

6. 技术约束
单文件 index.html，内联 CSS + JS，无构建步骤，无本地素材，不引入第三方框架和图片，不使用内联事件。轮播状态用 data-index 记录当前是第几条，切换时更新评价文字与评价人；滚动监听用 IntersectionObserver，不用 scroll 事件直接改样式。

7. 验收
代码后列出标题层级、键盘、窄屏和空状态检查结果；动效检查：缓动是不是 cubic-bezier(0.4,0,0.2,1)、超调是不是 0%、时长在 400–700ms 内、单次运动不超 1/3、次要层和环境层是否齐全；全页时序一致性检查：五个区块是否共用同一个人格和同一套缓动/时长档、入场顺序是否按区块顺序依次触发、有没有两个区块的动效同时抢主角、轮播切换时首屏与产品区的动效是否已停稳；无法判断的项目标注“需浏览器实测”。
```
