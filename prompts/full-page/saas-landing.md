# SaaS Landing — SaaS 落地页全页：导航 + 首屏 + 功能 + 定价 + FAQ + 页脚

人格：Corporate｜情绪：平静｜适用：SaaS 落地页、订阅产品官网

## 提示词（复制给 AI）

```
你是一名重视可访问性的前端工程师。请用原生 HTML、CSS 和 JavaScript 制作一个中文 SaaS 产品（示例产品）的响应式落地页全页，核心是六个区块按一条冷静、专业的动线串成一页。

1. 角色与目标
你是一名重视可访问性的前端工程师，同时是这个 SaaS 产品的第一位访客向导。页面最终要帮助第一次来的访客在 1 分钟内搞清产品是做什么的、凭什么值得试用，并在页末找到“开始试用”操作；已经了解产品的访客要能直接跳到定价或 FAQ，不被首屏动效挡路。

2. 页面类型与结构
这是一个单页落地页，按顺序必须包含以下六个区块，一个不少，顺序不换：
- 顶部导航：产品名（示例产品）+ 4 个锚点链接（功能 / 定价 / 常见问题 / 联系）+ 一个“开始试用”按钮；滚动后导航收紧。
- 首屏：主标题（不超过 12 个字）+ 一句话副标题 + 两个按钮（主按钮“开始试用”、次按钮“查看功能”）+ 一行示例数据（用“示例”标注，不写真实数字）。
- 功能区：区块标题 + 6 张功能卡（每张：编号 + 标题 + 一句话说明），三列排列。
- 定价区：区块标题 + 月付/年付切换开关（年付标注“省 20%”）+ 三档价格卡（每档：档名 + 价格 + 按月计价说明 + 5 条功能清单 + 一个按钮），中间档为推荐档（顶部“推荐”角标、边框强调、静态抬升 8px）。
- FAQ 区：区块标题 + 4 条问答（点击问题展开答案，一次只展开一条）。
- 页脚：四列链接（产品 / 资源 / 公司 / 联系，均为示例链接文字）+ 底部一行（示例公司名 + 版权占位年份）。

3. 真实内容与事实边界
产品类型只写通用类型，产品名、公司名一律用“示例产品”“示例公司”等明显占位写法，不编逼真品牌名。价格用明确占位数字（如 ¥99/月），年付按月付 8 折显示。不要编造客户数量、奖项、统计数据和服务承诺；未知数据用明确占位（如“示例数据”）。功能清单每条不超过 10 个字。

4. 视觉规则
浅色背景（白底 + 浅灰分区），单一深色强调（深蓝），标题中等字重；圆角 12px；最大内容宽度 1200px；无渐变和装饰性光晕。
人格 Corporate，全篇只用一种人格。标志性缓动 cubic-bezier(0.2,0,0,1)，超调 0–3%。
主情绪平静：所有入场都用轻柔曲线、慢而受控的上移淡入，200–400ms，不弹跳、不抢眼。

5. 交互与状态
- 全页串联（这是整页提示词的关键）：六个区块共用同一个人格 Corporate 和同一套缓动/时长档（cubic-bezier(0.2,0,0,1)，200–400ms），不许某个区块换人格、换缓动。区块之间的衔接用“收尾—开场”过渡：上一区块的最后一组元素完全入场后，下一区块的首元素才开始入场（IntersectionObserver threshold 0.2 触发，区块内元素依次延迟 80ms 出现）；区块之间不做整屏跳切、不做视差、不做翻页，衔接只靠统一的上移淡入 + 80ms  stagger，保持一根动线。
- 导航收缩：滚动超过 40px 时导航进入 compact 状态——Logo 缩放 0.92（200ms）、导航底边分隔线透明度 0→1（300ms）；回到顶部时恢复。导航在位，不遮挡锚点跳转后的区块标题。
- 首屏入场：标题、副标题、按钮组、示例数据行依次上移淡入（透明度 0→1 + 上移 20px，300ms，间隔 80ms）。
- 功能卡入场：进入视口 20% 时依次淡入上移（300ms，间隔 80ms）；卡片图标（次要层）比卡片晚 100ms 出现，幅度为主卡片的 30%（上移 8px 对 20px）；悬停时卡片上移 4px（300ms），无缩放、无弹跳。
- 定价切换：点击切换开关，滑块平移到另一侧（300ms）；价格数字淡出上移 12px 后换成新价格淡入（300ms）；年付价格按月付 8 折显示；切换开关是 button 元素（aria-pressed），可用键盘操作。
- FAQ 展开：点击问题，答案区展开（350ms），箭头旋转 180°（300ms），aria-expanded 同步更新；展开新的一条时已展开的自动收起。
- 页脚入场：滚动到底部时链接列依次淡入（300ms，间隔 80ms）。
- 环境层：首屏背景有极轻微的光晕呼吸（透明度 0.97–1 循环，3000ms ease-in-out），从不抢注意力。
- 每时每刻只有一个主角，其他元素暗到 40–60%。

6. 技术约束
单文件 index.html，内联 CSS + JS，无构建步骤，无本地素材，不引入第三方框架和图片，不使用内联事件。滚动监听用 requestAnimationFrame 节流，不用 scroll 事件直接改样式。锚点跳转用 CSS scroll-behavior 平滑滚动，不用 JS 动画滚动。

7. 验收
代码后列出标题层级、键盘、窄屏和空状态检查结果；动效检查：缓动是不是 cubic-bezier(0.2,0,0,1)、超调在 0–3% 内、时长在 200–400ms 内、单次运动不超 1/3、次要层和环境层是否齐全；全页时序一致性检查：六个区块是否共用同一个人格和同一套缓动/时长档、入场顺序是否按区块顺序依次触发、有没有两个区块的动效同时抢主角、导航收缩后锚点标题是否仍可见；无法判断的项目标注“需浏览器实测”。
```
