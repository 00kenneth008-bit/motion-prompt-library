# FAQ Section — 手风琴展开收起

人格：Corporate｜情绪：平静｜适用：SaaS 帮助页、落地页问答区、后台说明页

## 提示词（复制给 AI）

```
你是一名重视可访问性的前端工程师。请用原生 HTML、CSS 和 JavaScript 制作一个中文产品的响应式 FAQ 区块，核心是手风琴展开收起。

目标：让用户快速扫过 5 个常见问题，点开任意一个看到答案，并能用键盘完成全部操作。

页面结构：区块标题区（小标题 + 主标题）、5 条问答（每条：问题行 + 答案区），第一条默认展开、其余收起；问题行右侧有箭头图标。

内容要求：主标题不超过 12 个字；每个问题不超过 20 个字，答案不超过 60 个字；不要编造政策、价格以外的承诺；未知数据用明确占位。

视觉规范：白色或浅灰背景，单一蓝色强调；标题中等字重；圆角 8px；最大内容宽度 800px；无渐变和装饰性光晕。
人格 Corporate，全篇只用一种人格。标志性缓动 cubic-bezier(0.2,0,0,1)，超调 0–3%。
主情绪平静：展开收起都用平滑、流动的轻柔曲线，200–400ms。

交互要求：
- 展开收起：点击问题行，答案区展开（350ms，cubic-bezier(0.2,0,0,1)）；同一时间只展开一条，展开新的一条时旧的自动收起。
- 展开方式：答案区高度变化用 grid-template-rows 0fr→1fr 过渡（手风琴的标准做法，避免内容被压扁）；答案文字同步淡入上移 8px（透明度 0→1 + 上移 8px，350ms）。高度过渡是本页唯一例外：内容层仍只动 transform + opacity。
- 箭头旋转：展开时箭头图标旋转 180°（350ms，cubic-bezier(0.2,0,0,1)）；收起时转回。
- 键盘操作：问题行是 button 元素（aria-expanded），Tab 到达后回车/空格同样展开收起；焦点可见。
- 按钮 hover 时背景色加深 5%，200ms；无缩放、无弹跳。
- 次要层：答案文字比展开动作晚 50ms 出现，幅度为主区域的 30%。
- 环境层：无（Corporate 人格不需要环境层，保持干净）。
- 每时每刻只有一个主角，其他元素暗到 40–60%。

技术约束：单文件输出，不引入第三方框架和图片，不使用内联事件；展开状态用 aria-expanded 同步，答案区用 hidden 属性控制可访问性。
响应式：390px、768px、1440px 无横向滚动，正文不小于 16px。

验收：代码后列出标题层级、键盘、窄屏和空状态检查结果；动效检查：缓动是不是 (0.2,0,0,1)、超调在 0–3% 内、时长在 200–400ms 内、同一时间是否只展开一条、键盘操作是否同样生效、次要层是否齐全；无法判断的项目标注“需浏览器实测”。
```
