# Features Section — 三列功能卡滚动揭示

人格：Corporate｜情绪：平静｜适用：SaaS 落地页、仪表盘、后台产品页

## 提示词（复制给 AI）

```
你是一名重视可访问性的前端工程师。请用原生 HTML、CSS 和 JavaScript 制作一个中文 SaaS 产品的响应式落地页功能区块，核心是三列功能卡滚动揭示。

目标：让向下滚动的用户一次看清 3 个核心功能，每张卡片标题、说明、链接齐全，并在区块末尾找到“查看全部功能”操作。

页面结构：区块标题区（小标题 + 主标题 + 一句话说明）、三列功能卡（每张卡片：图标 + 功能名 + 两行说明 + 一个文字链接）、区块末尾一个次要按钮。

内容要求：主标题不超过 12 个字；每张卡片功能名不超过 6 个字，说明不超过 30 个字；不要编造客户 Logo、奖项、统计数字；未知数据用明确占位。

视觉规范：白色或浅灰背景，单一蓝色强调；标题中等字重；圆角 8px；最大内容宽度 1200px；无渐变和装饰性光晕。
人格 Corporate，全篇只用一种人格。标志性缓动 cubic-bezier(0.2,0,0,1)，超调 0–3%。
主情绪平静：揭示用平滑、流动的轻柔曲线，200–400ms。
揭示规则：用 IntersectionObserver，区块进入视口 20% 时触发；已揭示的不重复触发。

交互要求：
- 卡片揭示：三张卡片依次淡入（透明度 0→1 + 上移 16px，400ms，cubic-bezier(0.2,0,0,1)），间隔 80ms。
- 卡片悬停：悬停时卡片上移 4px（200ms，cubic-bezier(0.2,0,0,1)），链接文字下划线淡入；无缩放、无弹跳。
- 按钮 hover 时背景色加深 10%，200ms。
- 次要层：每张卡片内的图标比卡片主体晚 100ms 出现，幅度为主卡片的 30%。
- 环境层：无（Corporate 人格不需要环境层，保持干净）。
- 每时每刻只有一个主角，其他元素暗到 40–60%。

技术约束：单文件输出，不引入第三方框架和图片，不使用内联事件；滚动监听用 IntersectionObserver + requestAnimationFrame，不用 scroll 事件直接改样式。
响应式：390px、768px、1440px 无横向滚动，正文不小于 16px；窄屏时三列改为单列纵向排列。

验收：代码后列出标题层级、键盘、窄屏和空状态检查结果；动效检查：缓动是不是 (0.2,0,0,1)、超调在 0–3% 内、时长在 200–400ms 内、揭示阈值是不是 20%、次要层是否齐全；无法判断的项目标注“需浏览器实测”。
```

## 实测状态

- 已实测（2026-11-25）：按提示词生成单文件页面，结构检查 13/13 通过（缓动、时长、延迟、次要层、环境层、响应式），无头浏览器真实渲染截图核实，页面正常显示，无 JS 报错；滚动到 45% 实测 7 个元素已揭示，悬停中间卡片上移 4px；390px 无横向滚动，正文 17px。测试页：tests/sections/features-section.html，截图 tests/sections/screenshots/features-section.png。注：中途修过一次——`.reveal.visible` 的 translateY(0) 与 `:hover` 同优先级、后定义赢，导致悬停抬升被盖住，已加 `.card.reveal.visible:hover` 高优先级规则修好。
