# Pricing Section — 三档定价卡 + 月付年付切换

人格：Premium｜情绪：优雅｜适用：SaaS 定价页、订阅产品、会员页

## 提示词（复制给 AI）

```
你是一名重视可访问性的前端工程师。请用原生 HTML、CSS 和 JavaScript 制作一个中文订阅产品的响应式定价区块，核心是三档价格卡与月付/年付切换。

目标：让用户一眼分清三档区别、看到推荐档，并能切换月付/年付看到对应价格，最后在推荐档找到“开始试用”操作。

页面结构：区块标题区（小标题 + 主标题 + 一句话说明）、月付/年付切换开关（年付标注“省 20%”）、三档价格卡（每档：档名 + 价格 + 按月计价说明 + 5 条功能清单 + 一个按钮），中间档为推荐档（顶部“推荐”角标、边框强调、轻微抬升）、区块末尾一行小字（随时取消、无需信用卡）。

内容要求：主标题不超过 12 个字；每档功能清单 5 条，每条不超过 10 个字；价格用明确占位数字（如 ¥99/月），切换年付后显示对应折后价；不要编造客户数量、折扣以外的承诺；未知数据用明确占位。

视觉规范：深色背景（近黑），单一浅色强调（米白或淡金）；标题中等字重，字间距宽松；圆角 12px；最大内容宽度 1200px；无渐变和装饰性光晕。
人格 Premium，全篇只用一种人格。标志性缓动 cubic-bezier(0.4,0,0.2,1)，超调 0%。
主情绪优雅：切换与入场都用慢、受控的长弧线，400–700ms。

交互要求：
- 入场：三张价格卡依次淡入上移（透明度 0→1 + 上移 20px，600ms，cubic-bezier(0.4,0,0.2,1)），间隔 120ms；推荐档的角标晚 150ms 淡入。
- 月付/年付切换：点击切换开关，滑块平移到另一侧（400ms，cubic-bezier(0.4,0,0.2,1)）；价格数字淡出上移 12px 后换成新价格淡入（透明度 0→1 + 上移 12px，400ms）；年付价格按月付 8 折显示。
- 推荐档：静态抬升 8px（不做动画），边框用强调色；悬停时透明度 0.92，400ms；无缩放、无弹跳。
- 按钮 hover 时透明度 0.85，400ms。
- 次要层：每档功能清单比价格晚 100ms 出现，幅度为主卡片的 30%。
- 环境层：背景有极轻微的光晕呼吸（透明度 0.97–1 循环，3000ms），从不抢注意力。
- 每时每刻只有一个主角，其他元素暗到 40–60%。

技术约束：单文件输出，不引入第三方框架和图片，不使用内联事件；切换开关是 button 元素（aria-pressed），可用键盘操作。
响应式：390px、768px、1440px 无横向滚动，正文不小于 16px；窄屏时三档改为单列纵向排列，推荐档仍在中间。

验收：代码后列出标题层级、键盘、窄屏和空状态检查结果；动效检查：缓动是不是 (0.4,0,0.2,1)、超调是不是 0%、时长在 400–700ms 内、切换后价格是否正确变为 8 折、次要层和环境层是否齐全；无法判断的项目标注“需浏览器实测”。
```
