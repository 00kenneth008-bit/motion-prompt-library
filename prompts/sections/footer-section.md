# Footer Section — 多列链接 + 订阅输入框

人格：Corporate｜情绪：平静｜适用：落地页页脚、官网页脚、后台页脚

## 提示词（复制给 AI）

```
你是一名重视可访问性的前端工程师。请用原生 HTML、CSS 和 JavaScript 制作一个中文产品的响应式页脚区块，核心是多列链接与订阅输入框。

目标：让滑到页底的用户快速找到产品、公司、帮助三类链接，并能留邮箱订阅更新，提交后看到明确的成功反馈。

页面结构：页脚分四列（品牌列：Logo + 一句话介绍 + 社交图标占位；产品列：5 个链接；公司列：4 个链接；订阅列：标题 + 一句话说明 + 邮箱输入框 + 订阅按钮）、底栏（一行版权小字 + 隐私/条款链接）。

内容要求：链接文字用真实栏目名或明确占位；订阅说明一句话；不要编造社交账号、备案号以外的信息；未知数据用明确占位。

视觉规范：白色或浅灰背景，单一蓝色强调；标题中等字重；圆角 8px；最大内容宽度 1200px；无渐变和装饰性光晕。
人格 Corporate，全篇只用一种人格。标志性缓动 cubic-bezier(0.2,0,0,1)，超调 0–3%。
主情绪平静：揭示与反馈都用平滑、流动的轻柔曲线，200–400ms。
揭示规则：用 IntersectionObserver，页脚进入视口 20% 时触发；已揭示的不重复触发。

交互要求：
- 揭示：四列依次淡入（透明度 0→1 + 上移 16px，400ms，cubic-bezier(0.2,0,0,1)），间隔 80ms。
- 订阅提交：输入邮箱后点订阅，按钮先变“提交中…”（禁用态，300ms）；成功后输入框与按钮淡出，成功提示淡入上移 12px（透明度 0→1 + 上移 12px，400ms），提示文字“订阅成功，每周一封更新发到你的邮箱”。
- 订阅校验：邮箱格式不对时，输入框边框变红（颜色直接切换，不做过渡），错误提示淡入（透明度 0→1，200ms），不提交。
- 链接 hover 时颜色加深，200ms；无缩放、无弹跳。
- 次要层：底栏版权文字比四列晚 100ms 出现，幅度为主区域的 30%。
- 环境层：无（Corporate 人格不需要环境层，保持干净）。
- 每时每刻只有一个主角，其他元素暗到 40–60%。

技术约束：单文件输出，不引入第三方框架和图片，不使用内联事件；订阅用表单 submit 事件处理，不刷新页面；邮箱输入框有 label 关联。
响应式：390px、768px、1440px 无横向滚动，正文不小于 16px；窄屏时四列改为单列纵向排列，订阅列在最上方。

验收：代码后列出标题层级、键盘、窄屏和空状态检查结果；动效检查：缓动是不是 (0.2,0,0,1)、超调在 0–3% 内、时长在 200–400ms 内、揭示阈值是不是 20%、订阅成功态是否正确出现、错误提示是否正确出现、次要层是否齐全；无法判断的项目标注“需浏览器实测”。
```
