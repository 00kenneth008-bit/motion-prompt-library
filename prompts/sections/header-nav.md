# Header Nav — 滚动收缩导航 + 移动端汉堡菜单

人格：Premium｜情绪：优雅｜适用：官网导航、落地页导航、品牌站导航

## 提示词（复制给 AI）

```
你是一名重视可访问性的前端工程师。请用原生 HTML、CSS 和 JavaScript 制作一个中文产品的响应式顶部导航，核心是滚动时收缩与移动端汉堡菜单。

目标：让用户在任何位置都能回到导航，滚动后导航变紧凑不占地方，手机上点汉堡能展开完整菜单。

页面结构：顶部导航（Logo + 4 个链接 + 一个主按钮，吸顶固定）、导航下方一段演示内容（标题 + 两段文字，足够长以便滚动）、移动端汉堡菜单面板（全宽下拉，4 个链接 + 一个主按钮）。

内容要求：链接文字用真实栏目名或明确占位；演示内容标题不超过 12 个字；不要编造数据；未知数据用明确占位。

视觉规范：白色背景，单一深色强调；标题中等字重；圆角 8px；最大内容宽度 1200px；无渐变和装饰性光晕。
人格 Premium，全篇只用一种人格。标志性缓动 cubic-bezier(0.4,0,0.2,1)，超调 0%。
主情绪优雅：收缩与菜单展开都用慢、受控的长弧线，400–700ms。

交互要求：
- 滚动收缩：向下滚动超过 80px 时导航进入紧凑态；高度本身直接切换（不做过渡，避免布局属性动画），Logo 缩放 0.92、上移 4px，链接整体上移 4px，底部细边框淡入（透明度 0→1，400ms，cubic-bezier(0.4,0,0.2,1)）；滚回顶部恢复原态。
- 汉堡菜单：390px–768px 宽度下显示汉堡按钮，桌面链接隐藏；点击汉堡，菜单面板从导航下方淡入下滑（透明度 0→1 + 上移 8px，400ms，cubic-bezier(0.4,0,0.2,1)），菜单内 4 个链接依次淡入，间隔 60ms；再点汉堡或点任意链接后菜单收起；汉堡图标变叉号（两条线旋转，transform，400ms）。
- 按钮 hover 时透明度 0.85，400ms；无缩放、无弹跳。
- 次要层：导航下方的细边框比收缩动作晚 100ms 出现，幅度为主导航的 30%。
- 环境层：无（导航不需要环境层，保持干净）。
- 每时每刻只有一个主角，其他元素暗到 40–60%。

技术约束：单文件输出，不引入第三方框架和图片，不使用内联事件；汉堡按钮是 button 元素（aria-expanded），菜单用 aria-hidden 同步；滚动监听用 requestAnimationFrame 节流，不用 scroll 事件直接改样式。
响应式：390px、768px、1440px 无横向滚动，正文不小于 16px；768px 以下只显示 Logo、汉堡按钮、主按钮。

验收：代码后列出标题层级、键盘、窄屏和空状态检查结果；动效检查：缓动是不是 (0.4,0,0.2,1)、超调是不是 0%、时长在 400–700ms 内、滚动 80px 是否触发紧凑态、汉堡菜单是否正常展开收起、次要层是否齐全；无法判断的项目标注“需浏览器实测”。
```
