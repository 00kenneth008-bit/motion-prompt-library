# Loaders — 骨架屏 + 转圈 + 进度条三态

人格：Corporate｜情绪：平静｜适用：仪表盘、后台、列表页、数据页

## 提示词（复制给 AI）

```
你是一名重视可访问性的前端工程师。请用原生 HTML、CSS 和 JavaScript 制作一个中文产品的响应式加载器组件展示页，核心是骨架屏、转圈、进度条三种加载态。

目标：让使用者一眼分清三种加载态分别用在什么场景，并能逐个看到它们的完整动画过程。

页面结构：页面标题（一句话说明）、三张演示卡横向排列（每张：类型名 + 一句话场景说明 + 演示区 + 一个“重新播放”按钮）。

内容要求：场景说明一句话；演示区内容用明确占位（如“标题占位”“正文占位行”）；不要编造数据；未知数据用明确占位。

视觉规范：白色或浅灰背景，单一蓝色强调；标题中等字重；圆角 8px；最大内容宽度 1200px；无渐变和装饰性光晕。
人格 Corporate，全篇只用一种人格。标志性缓动 cubic-bezier(0.2,0,0,1)，超调 0–3%。
主情绪平静：加载动画都用平滑、流动的轻柔曲线，200–400ms；转圈与进度条的线性动画是铁律允许的唯一例外（仅限转圈、进度条、计时器）。

交互要求：
- 骨架屏：占位块透明度 0.6→1 循环呼吸（1200ms，正弦 ease-in-out），模拟内容正在加载；骨架块本身只用 opacity 动画，不做位移动画。
- 转圈：圆形 spinner 旋转（800ms 一圈，linear 匀速无限循环，铁律允许的例外）；转圈下方一行“加载中…”文字。
- 进度条：填充条用 scaleX（transform，左端为原点）从 0 伸到 1（2000ms，cubic-bezier(0.2,0,0,1)），右侧同步显示百分比数字（0%→100%）；到 100% 后显示“加载完成”。
- 重新播放：点任意一张卡的“重新播放”，该卡的加载动画从头再跑一次；不影响其他两张卡。
- 按钮 hover 时背景色加深 10%，200ms；无缩放、无弹跳。
- 次要层：每张卡的类型名比演示区晚 100ms 出现，幅度为主卡片的 30%。
- 环境层：无（Corporate 人格不需要环境层，保持干净）。
- 每时每刻只有一个主角，其他元素暗到 40–60%。

技术约束：单文件输出，不引入第三方框架和图片，不使用内联事件；进度条不用 width 做动画，必须用 scaleX；百分比数字用 JS 更新。
响应式：390px、768px、1440px 无横向滚动，正文不小于 16px；窄屏时三张卡改为单列纵向排列。

验收：代码后列出标题层级、键盘、窄屏和空状态检查结果；动效检查：缓动是不是 (0.2,0,0,1)、超调在 0–3% 内、骨架屏是否只用 opacity、转圈是否匀速旋转、进度条是不是 scaleX 且到 100%、重新播放是否只影响当前卡、次要层是否齐全；无法判断的项目标注“需浏览器实测”。
```
