# Cards — 悬停抬升卡片

人格：Premium｜情绪：优雅｜适用：宣传页、作品集、产品列表、博客

## 提示词（复制给 AI）

```
你是一名重视可访问性的前端工程师。请用原生 HTML、CSS 和 JavaScript 制作一个中文产品的响应式卡片组件展示页，核心是悬停抬升与阴影加深。

目标：让用户一眼看到 3 张内容卡片，悬停任意一张能感到它被“拿起来”，并能点进详情。

页面结构：页面标题（一句话说明）、三张卡片横向排列（每张：配图区 + 标题 + 两行说明 + 一个文字链接“了解更多 →”）。

内容要求：卡片标题不超过 10 个字，说明不超过 30 个字；不要编造数据、奖项；未知数据用明确占位。

视觉规范：深色背景（近黑），单一浅色强调（米白或淡金）；标题中等字重，字间距宽松；圆角 12px；最大内容宽度 1200px；无渐变和装饰性光晕。
人格 Premium，全篇只用一种人格。标志性缓动 cubic-bezier(0.4,0,0.2,1)，超调 0%。
主情绪优雅：抬升与入场都用慢、受控的长弧线，400–700ms。

交互要求：
- 入场：三张卡片依次淡入上移（透明度 0→1 + 上移 20px，600ms，cubic-bezier(0.4,0,0.2,1)），间隔 120ms。
- 悬停抬升：鼠标悬停一张卡片，它上移 8px（500ms，cubic-bezier(0.4,0,0.2,1)）；阴影加深不用 box-shadow 过渡，用独立阴影层（::after）淡入（透明度 0→1，500ms）；配图区轻微放大 1.03（500ms）；链接箭头右移 4px（400ms）；鼠标离开全部复位。
- 键盘聚焦：Tab 聚焦到卡片时同样抬升；卡片是可聚焦元素（tabindex="0"），链接可用键盘到达。
- 点击：点击卡片任意处，卡片轻微下沉 2px 后弹回（200ms）。
- 次要层：配图区放大比卡片抬升晚 100ms，幅度为主卡片的 30%。
- 环境层：背景有极轻微的光晕呼吸（透明度 0.97–1 循环，3000ms），从不抢注意力。
- 每时每刻只有一个主角，其他元素暗到 40–60%。

技术约束：单文件输出，不引入第三方框架和图片，不使用内联事件；配图区用纯色块 + emoji 占位，不用真实图片。
响应式：390px、768px、1440px 无横向滚动，正文不小于 16px；窄屏时三张卡片改为单列纵向排列。

验收：代码后列出标题层级、键盘、窄屏和空状态检查结果；动效检查：缓动是不是 (0.4,0,0.2,1)、超调是不是 0%、时长在 400–700ms 内、悬停是否上移 8px、阴影是否用独立层淡入、键盘聚焦是否同样抬升、次要层和环境层是否齐全；无法判断的项目标注“需浏览器实测”。
```
