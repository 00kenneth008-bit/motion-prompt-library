# Forms — 浮动标签输入框 + 提交成功态

人格：Corporate｜情绪：平静｜适用：注册页、联系页、后台表单、订阅页

## 提示词（复制给 AI）

```
你是一名重视可访问性的前端工程师。请用原生 HTML、CSS 和 JavaScript 制作一个中文产品的响应式表单组件页，核心是输入框聚焦浮动标签与提交成功态。

目标：让用户填三个字段（姓名、邮箱、留言）时标签始终可见，提交后明确看到成功反馈，填错时明确看到错在哪。

页面结构：页面标题（一句话说明）、表单卡片（姓名输入框、邮箱输入框、留言文本框、提交按钮）、成功面板（默认隐藏：对勾图标 + 成功标题 + 一句话说明 + “再填一份”按钮）。

内容要求：标签文字用真实字段名；占位提示一句话；成功说明一句话；不要编造数据；未知数据用明确占位。

视觉规范：白色或浅灰背景，单一蓝色强调；标题中等字重；圆角 8px；最大内容宽度 640px；无渐变和装饰性光晕。
人格 Corporate，全篇只用一种人格。标志性缓动 cubic-bezier(0.2,0,0,1)，超调 0–3%。
主情绪平静：标签浮动与状态切换都用平滑、流动的轻柔曲线，200–400ms。

交互要求：
- 浮动标签：输入框聚焦或已有内容时，标签上移 18px 并缩小到 0.8 倍（300ms，cubic-bezier(0.2,0,0,1)，只动 transform）；失焦且内容为空时标签回到框内原位。
- 聚焦态：输入框聚焦时边框变强调色（颜色直接切换，不做过渡），标签同步变强调色。
- 校验：提交时姓名为空、邮箱格式不对或留言为空，对应输入框边框变红（颜色直接切换），错误提示淡入（透明度 0→1，200ms）；修正后错误提示淡出。
- 提交成功：校验通过后按钮变“提交中…”（禁用态，300ms），随后表单整体淡出下移 12px（透明度 1→0 + 下移 12px，400ms），成功面板淡入上移 12px（透明度 0→1 + 上移 12px，400ms）；对勾图标从 0.9 缩放到 1（300ms，cubic-bezier(0.2,0,0,1)）。
- 再填一份：点成功面板的按钮，成功面板淡出，表单清空后淡入复位。
- 次要层：错误提示比边框变色晚 50ms 出现，幅度为主表单的 30%。
- 环境层：无（Corporate 人格不需要环境层，保持干净）。
- 每时每刻只有一个主角，其他元素暗到 40–60%。

技术约束：单文件输出，不引入第三方框架和图片，不使用内联事件；提交用表单 submit 事件处理，不刷新页面；每个输入框有 label 关联；错误提示用 aria-live 播报。
响应式：390px、768px、1440px 无横向滚动，正文不小于 16px。

验收：代码后列出标题层级、键盘、窄屏和空状态检查结果；动效检查：缓动是不是 (0.2,0,0,1)、超调在 0–3% 内、时长在 200–400ms 内、标签浮动是否只动 transform、校验错误是否正确出现、提交成功态是否正确出现、次要层是否齐全；无法判断的项目标注“需浏览器实测”。
```
