# Buttons — 主/次/幽灵按钮三态

人格：Playful｜情绪：喜悦｜适用：落地页、活动页、轻松产品、儿童产品

## 提示词（复制给 AI）

```
你是一名重视可访问性的前端工程师。请用原生 HTML、CSS 和 JavaScript 制作一个中文产品的响应式按钮组件展示页，核心是主按钮、次按钮、幽灵按钮的三态（悬停/点击/禁用）。

目标：让使用者一眼分清三种按钮的用途，并能逐个试出悬停、点击、禁用三种状态。

页面结构：页面标题（一句话说明）、三组按钮演示（每组：组名 + 主按钮/次按钮/幽灵按钮各一个正常态 + 一个禁用态，横向排列）、每组下方一行状态说明文字。

内容要求：按钮文字不超过 6 个字；状态说明一句话；不要编造数据；未知数据用明确占位。

视觉规范：浅色背景，单一亮色强调（橙色）；标题大字重；圆角 16px；最大内容宽度 1200px；无渐变和装饰性光晕。
人格 Playful，全篇只用一种人格。标志性缓动 ease-out-back（cubic-bezier(0.68,-0.55,0.27,1.55)），超调 10–20%。
主情绪喜悦：悬停与点击都用弹跳、弧线路径，向上，150–300ms。

交互要求：
- 入场：三组按钮依次弹入（透明度 0→1 + 上移 12px + 缩放 0.95→1，300ms，ease-out-back），间隔 80ms。
- 悬停：任意按钮悬停时放大 1.05（200ms，ease-out-back），主按钮阴影加深（独立阴影层淡入，不直接过渡 box-shadow）；次按钮边框加粗一档（颜色直接切换，不做过渡）。
- 点击：按下时缩小 0.95（150ms，ease-out-back），松开弹回 1；点击处出现涟漪（一个圆形 span 从点击点缩放 0→1 并淡出，400ms，transform + opacity）。
- 禁用：禁用态按钮透明度 0.5，鼠标指针为 not-allowed，悬停与点击均无反应。
- 次要层：按钮内的图标比按钮主体晚 50ms 出现，幅度为主按钮的 30%。
- 环境层：背景漂浮 3 个小图形（星星/圆点），幅度为主按钮的 30–50%，比主层晚 50–100ms。
- 每时每刻只有一个主角，其他元素暗到 40–60%。

技术约束：单文件输出，不引入第三方框架和图片，不使用内联事件；涟漪元素用 JS 创建并在动画结束后移除；禁用按钮用 disabled 属性。
响应式：390px、768px、1440px 无横向滚动，正文不小于 16px；窄屏时每组按钮改为纵向排列。

验收：代码后列出标题层级、键盘、窄屏和空状态检查结果；动效检查：缓动是不是 ease-out-back、超调在 10–20% 内、时长在 150–300ms 内、悬停是否放大 1.05、点击是否缩小 0.95、禁用态是否无反应、次要层和环境层是否齐全；无法判断的项目标注“需浏览器实测”。
```
