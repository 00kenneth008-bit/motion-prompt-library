# Corporate Hero — 干净利落首屏

人格：Corporate｜情绪：平静｜适用：仪表盘、后台、管理工具、SaaS

## 提示词（复制给 AI）

```
你是一名重视可访问性的前端工程师。请用原生 HTML、CSS 和 JavaScript 制作一个中文 SaaS 产品的响应式落地页首屏。

目标：让第一次访问的用户在 3 秒内理解产品解决什么问题，并在首屏找到“开始使用”操作。

页面结构：顶部导航（Logo + 4 个链接 + 登录/注册）、首屏 Hero（主标题、副标题、两个按钮、产品截图/示意图）、一行 3 个数据指标。

内容要求：主标题不超过 12 个字；副标题一句话说清价值；数据指标用真实数字或明确占位；不要编造客户 Logo、奖项。

视觉规范：白色或浅灰背景，单一蓝色强调；标题中等字重；圆角 8px；最大内容宽度 1200px；无渐变和装饰性光晕。
人格 Corporate，全篇只用一种人格。标志性缓动 cubic-bezier(0.2,0,0,1)，超调 0–3%。
主情绪平静：入场用平滑、流动的轻柔曲线，500–1000ms。

交互要求：
- 首屏元素依次淡入：标题先（400ms，cubic-bezier(0.2,0,0,1)，透明度 0→1），副标题晚 80ms，按钮晚 160ms，示意图晚 240ms（透明度 0→1 + 上移 12px，400ms）。
- 示意图静止，不循环动；hover 时无变化。
- 按钮 hover 时背景色加深 10%，200ms；无缩放、无弹跳。
- 次要层：数据指标数字在滚动到视口时从 0 计数到目标值，800ms，幅度为主视觉的 30%。
- 环境层：无（Corporate 人格不需要环境层，保持干净）。
- 每时每刻只有一个主角，其他元素暗到 40–60%。

技术约束：单文件输出，不引入第三方框架和图片，不使用内联事件。
响应式：390px、768px、1440px 无横向滚动，正文不小于 16px。

验收：代码后列出标题层级、键盘、窄屏和空状态检查结果；动效检查：缓动是不是 (0.2,0,0,1)、超调在 0–3% 内、时长在 200–400ms 内、计数动画是否正常；无法判断的项目标注“需浏览器实测”。
```
