# Playful Hero — 弹跳入场首屏

人格：Playful｜情绪：喜悦｜适用：儿童产品、轻松工具、庆祝页

## 提示词（复制给 AI）

```
你是一名重视可访问性的前端工程师。请用原生 HTML、CSS 和 JavaScript 制作一个中文儿童产品的响应式落地页首屏。

目标：让第一次访问的家长在 3 秒内理解产品是什么，并在首屏找到“免费试用”操作。

页面结构：顶部导航（Logo + 3 个链接 + 试用按钮）、首屏 Hero（主标题、副标题、两个按钮、主视觉）、一行 3 个信任标识。

内容要求：主标题不超过 10 个字；副标题一句话说清价值；不要编造用户数量、奖项；未知数据用明确占位。

视觉规范：浅色背景，单一亮色强调（橙色或绿色）；标题大字重，圆角 16px；最大内容宽度 1200px；无渐变和装饰性光晕。
人格 Playful，全篇只用一种人格。标志性缓动 ease-out-back，超调 10–20%。
主情绪喜悦：入场用弹跳、弧线路径，向上。

交互要求：
- 首屏元素依次入场：标题先（ease-out-back，300ms，向上弹入），副标题晚 80ms，按钮晚 160ms，主视觉晚 240ms（缩放 0.9→1，带 15% 超调）。
- 主视觉每 3 秒轻轻弹跳一次（缩放 1→1.03→1，400ms），幅度不超过屏幕 1/3。
- 按钮 hover 时放大 1.05，300ms ease-out-back；点击时缩小 0.97。
- 次要层：背景漂浮 3 个小图形（星星/圆点），幅度为主视觉的 30–50%，比主层晚 50–100ms。
- 环境层：背景有极轻微的呼吸感（透明度 0.95–1 循环，2000ms），从不抢注意力。
- 每时每刻只有一个主角，其他元素暗到 40–60%。

技术约束：单文件输出，不引入第三方框架和图片，不使用内联事件。
响应式：390px、768px、1440px 无横向滚动，正文不小于 16px。

验收：代码后列出标题层级、键盘、窄屏和空状态检查结果；动效检查：入场顺序对不对、超调在 10–20% 内、单次运动不超 1/3、次要层和环境层是否齐全；无法判断的项目标注“需浏览器实测”。
```
