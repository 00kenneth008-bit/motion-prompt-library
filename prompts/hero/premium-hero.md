# Premium Hero — 优雅渐入首屏

人格：Premium｜情绪：优雅｜适用：宣传页、封面、品牌站

## 提示词（复制给 AI）

```
你是一名重视可访问性的前端工程师。请用原生 HTML、CSS 和 JavaScript 制作一个中文品牌产品的响应式落地页首屏。

目标：让第一次访问的用户感受到优雅和品质，并在首屏找到“了解更多”操作。

页面结构：顶部导航（Logo + 4 个链接）、首屏 Hero（主标题、副标题、一个主按钮、主视觉）、底部一行小字信任标识。

内容要求：主标题不超过 8 个字；副标题一句话；不要编造用户数量、奖项；未知数据用明确占位。

视觉规范：深色背景（近黑），单一浅色强调（米白或淡金）；标题中等字重，字间距宽松；最大内容宽度 1200px；无渐变和装饰性光晕。
人格 Premium，全篇只用一种人格。标志性缓动 cubic-bezier(0.4,0,0.2,1)，超调 0%。
主情绪优雅：入场用慢、受控的长弧线，400–700ms。

交互要求：
- 首屏元素依次淡入上移：标题先（600ms，cubic-bezier(0.4,0,0.2,1)，上移 20px + 透明度 0→1），副标题晚 120ms，按钮晚 240ms，主视觉晚 360ms（透明度 0→1，600ms）。
- 主视觉静止，不循环动；hover 时极轻微放大 1.02，600ms。
- 按钮 hover 时透明度 0.85，400ms；无缩放、无弹跳。
- 次要层：主视觉下方一条细线装饰，幅度为主视觉的 30%，晚 100ms 出现。
- 环境层：背景有极轻微的光晕呼吸（透明度 0.97–1 循环，3000ms），从不抢注意力。
- 每时每刻只有一个主角，其他元素暗到 40–60%。

技术约束：单文件输出，不引入第三方框架和图片，不使用内联事件。
响应式：390px、768px、1440px 无横向滚动，正文不小于 16px。

验收：代码后列出标题层级、键盘、窄屏和空状态检查结果；动效检查：缓动是不是 (0.4,0,0.2,1)、超调是不是 0%、时长在 400–700ms 内、次要层和环境层是否齐全；无法判断的项目标注“需浏览器实测”。
```
