# Energetic Hero — 醒目快闪首屏

人格：Energetic｜情绪：惊喜｜适用：活动页、预告、新品发布

## 提示词（复制给 AI）

```
你是一名重视可访问性的前端工程师。请用原生 HTML、CSS 和 JavaScript 制作一个中文活动页面的响应式落地页首屏。

目标：让第一次访问的用户立刻感受到活动的能量，并在首屏找到“立即参加”操作。

页面结构：顶部导航（Logo + 2 个链接）、首屏 Hero（活动标题、倒计时、一个主按钮、主视觉）、底部一行活动亮点。

内容要求：活动标题不超过 10 个字；倒计时用真实日期或明确占位；不要编造参与人数、奖项；未知数据用明确占位。

视觉规范：深色背景，单一亮色强调（亮黄或亮红）；标题大字重，全大写或加粗；圆角 4px；最大内容宽度 1200px；无渐变和装饰性光晕。
人格 Energetic，全篇只用一种人格。标志性缓动 ease-out-expo，超调 15–30%。
主情绪惊喜：入场用突然、扩张的径向向外，150–300ms。

交互要求：
- 首屏元素快速依次入场：标题先（200ms，ease-out-expo，缩放 0.8→1 + 透明度 0→1），副标题晚 60ms，倒计时晚 120ms，按钮晚 180ms，主视觉晚 240ms（缩放 0.9→1，带 20% 超调）。
- 主视觉每 2 秒脉冲一次（缩放 1→1.05→1，250ms），幅度不超过屏幕 1/3。
- 按钮 hover 时放大 1.08，200ms ease-out-expo；点击时缩小 0.95。
- 次要层：背景有 2 个快速划过的光带，幅度为主视觉的 30–50%，比主层晚 50ms。
- 环境层：背景有轻微的闪烁点（透明度 0.8–1 循环，1500ms），从不抢注意力。
- 每时每刻只有一个主角，其他元素暗到 40–60%。
- 慎用：全页只在首屏用 Energetic，其他区块用人格降一级的 Corporate，避免处处都炸。

技术约束：单文件输出，不引入第三方框架和图片，不使用内联事件。
响应式：390px、768px、1440px 无横向滚动，正文不小于 16px。

验收：代码后列出标题层级、键盘、窄屏和空状态检查结果；动效检查：缓动是不是 ease-out-expo、超调在 15–30% 内、时长在 100–250ms 内、单次运动不超 1/3、次要层和环境层是否齐全；无法判断的项目标注“需浏览器实测”。
```
