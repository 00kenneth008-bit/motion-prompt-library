# Card Flip 3D — 悬停 3D 翻转卡片

人格：Corporate｜情绪：平静｜适用：SaaS 功能介绍、仪表盘、后台

## 提示词（复制给 AI）

```
你是一名重视可访问性的前端工程师。请用原生 HTML、CSS 和 JavaScript 制作一个中文 SaaS 产品的响应式功能介绍页，核心是 3 张悬停 3D 翻转卡片。

目标：让第一次访问的用户在 3 秒内看到 3 个核心功能，悬停任意一张能看到详情，并在首屏找到“开始使用”操作。

页面结构：顶部导航（Logo + 4 个链接 + 登录/注册）、首屏（主标题、副标题、一个主按钮）、翻转卡片组（3 张卡片横向排列，正面是图标 + 功能名 + 一句话，背面是 3 条详情 + 一个链接）、底部一行小字。

内容要求：主标题不超过 12 个字；副标题一句话说清价值；卡片详情用真实功能点或明确占位；不要编造客户 Logo、奖项；未知数据用明确占位。

视觉规范：白色或浅灰背景，单一蓝色强调；标题中等字重；圆角 8px；最大内容宽度 1200px；无渐变和装饰性光晕。
人格 Corporate，全篇只用一种人格。标志性缓动 cubic-bezier(0.2,0,0,1)，超调 0–3%。
主情绪平静：入场和翻转都用平滑、流动的轻柔曲线，200–400ms。
翻转：卡片绕 Y 轴翻 180°，父容器 perspective 1000px，正反面 backface-visibility hidden。

交互要求：
- 入场：三张卡片依次淡入（透明度 0→1 + 上移 12px，400ms，cubic-bezier(0.2,0,0,1)），间隔 80ms。
- 悬停翻转：鼠标悬停一张卡片，它绕 Y 轴翻到背面（350ms，cubic-bezier(0.2,0,0,1)）；鼠标离开翻回正面。
- 键盘翻转：Tab 聚焦到卡片时同样翻到背面，失焦翻回；卡片是可聚焦元素（tabindex="0"），背面链接可用键盘到达。
- 点击固定：点击卡片则固定在背面，再点翻回；点击不影响其他卡片。
- 按钮 hover 时背景色加深 10%，200ms；无缩放、无弹跳。
- 次要层：卡片阴影随翻转轻微变化（幅度为主卡片的 30%），比主层晚 50ms。
- 环境层：无（Corporate 人格不需要环境层，保持干净）。
- 每时每刻只有一个主角，其他元素暗到 40–60%。

技术约束：单文件输出，不引入第三方框架和图片，不使用内联事件；3D 只用 CSS transform（perspective / rotateY），不引入 WebGL 库。
响应式：390px、768px、1440px 无横向滚动，正文不小于 16px；窄屏时三张卡片改为纵向排列。

验收：代码后列出标题层级、键盘、窄屏和空状态检查结果；动效检查：缓动是不是 (0.2,0,0,1)、超调在 0–3% 内、时长在 200–400ms 内、键盘聚焦是否同样翻转、次要层是否齐全；无法判断的项目标注“需浏览器实测”。
```
