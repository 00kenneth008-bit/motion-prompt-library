# Collectible 3D — 3D 收藏品展示，鼠标跟随视差

人格：Premium｜情绪：惊喜｜适用：收藏品、手办、限量产品、品牌站

## 提示词（复制给 AI）

```
你是一名重视可访问性的前端工程师。请用原生 HTML、CSS 和 JavaScript 制作一个中文限量手办收藏品的响应式展示页，核心是鼠标跟随的 3D 视差主视觉。

目标：让第一次访问的用户立刻被收藏品吸引，移动鼠标时感受到纵深，并在首屏找到“查看详情”操作。

页面结构：顶部导航（Logo + 4 个链接）、首屏（主标题、副标题、一个主按钮）、收藏品主视觉区（三层视差：前景手办、中间装饰环、背景光斑）、底部一行 3 个收藏数据（编号、限量、材质）。

内容要求：主标题不超过 8 个字；副标题一句话；收藏数据用真实数字或明确占位；不要编造用户数量、奖项；未知数据用明确占位。

视觉规范：深色背景（近黑），单一浅色强调（米白或淡金）；标题中等字重，字间距宽松；圆角 20px；最大内容宽度 1200px；无渐变和装饰性光晕。
人格 Premium，全篇只用一种人格。标志性缓动 cubic-bezier(0.4,0,0.2,1)，超调 0%。
主情绪惊喜：入场用突然、扩张的径向向外（ease-out-expo，150–300ms）；鼠标跟随的持续运动用 Premium 缓动 (0.4,0,0.2,1)，500ms。
视差三层：前景手办跟随鼠标幅度 100%，中间装饰环 50%，背景光斑 20%，三层错开才有纵深。

交互要求：
- 入场：主视觉从缩放 0.85 + 透明度 0 径向弹出（250ms，ease-out-expo），标题比主视觉早 100ms 淡入。
- 鼠标跟随：鼠标在主视觉区移动时，手办绕 X/Y 轴倾斜跟随（最大 10°，500ms，cubic-bezier(0.4,0,0.2,1)）；三层按 100%/50%/20% 幅度反向位移；鼠标离开后 500ms 平滑回正。
- 点击手办：轻微放大 1.03 + 光晕亮起（500ms，cubic-bezier(0.4,0,0.2,1)），再点恢复。
- 按钮 hover 时透明度 0.85，400ms；无缩放、无弹跳。
- 次要层：中间装饰环随鼠标转动，幅度为主视觉的 30–50%，比主层晚 50–100ms。
- 环境层：背景有极轻微的星尘呼吸（透明度 0.95–1 循环，3000ms），从不抢注意力。
- 每时每刻只有一个主角，其他元素暗到 40–60%。

技术约束：单文件输出，不引入第三方框架和图片，不使用内联事件；3D 只用 CSS transform（perspective / rotateX / rotateY / translate），不引入 WebGL 库；鼠标跟随用 requestAnimationFrame 节流。
响应式：390px、768px、1440px 无横向滚动，正文不小于 16px；触屏设备无鼠标时，主视觉改为手指拖动倾斜，幅度相同。

验收：代码后列出标题层级、键盘、窄屏和空状态检查结果；动效检查：入场缓动是不是 ease-out-expo、跟随缓动是不是 (0.4,0,0.2,1)、倾斜角度不超过 10°、三层视差幅度是不是 100%/50%/20%、次要层和环境层是否齐全；无法判断的项目标注“需浏览器实测”。
```
