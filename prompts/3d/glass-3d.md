# Glass 3D — 玻璃拟态 3D 纵深卡片

人格：Premium｜情绪：优雅｜适用：品牌宣传、高端产品、封面

## 提示词（复制给 AI）

```
你是一名重视可访问性的前端工程师。请用原生 HTML、CSS 和 JavaScript 制作一个中文高端耳机品牌的响应式落地页，核心是一组玻璃拟态 3D 纵深卡片。

目标：让第一次访问的用户感受到产品的品质和纵深感，并在首屏找到“了解更多”操作。

页面结构：顶部导航（Logo + 4 个链接）、首屏 Hero（主标题、副标题、一个主按钮）、玻璃卡片组（3 张卡片，前后错开纵深排列，每张一张图 + 一行标题 + 一行价格）、底部一行小字信任标识。

内容要求：主标题不超过 8 个字；副标题一句话；卡片价格用真实数字或明确占位；不要编造用户数量、奖项；未知数据用明确占位。

视觉规范：深色背景（近黑），单一浅色强调（米白或淡金）；卡片用玻璃拟态（半透明底 + 细边框 + 模糊背景，模糊只做静态效果，不参与动画）；标题中等字重，字间距宽松；圆角 20px；最大内容宽度 1200px；无渐变和装饰性光晕。
人格 Premium，全篇只用一种人格。标志性缓动 cubic-bezier(0.4,0,0.2,1)，超调 0%。
主情绪优雅：入场用慢、受控的长弧线，400–700ms。
纵深：三张卡片分别放在 translateZ(0)、translateZ(-60px)、translateZ(-120px)，父容器 perspective 1200px，卡片之间前后错开，不重叠。

交互要求：
- 卡片依次淡入上移：第一张先（600ms，cubic-bezier(0.4,0,0.2,1)，上移 20px + 透明度 0→1），第二张晚 120ms，第三张晚 240ms。
- 鼠标在卡片组上移动时，整组绕 X/Y 轴轻微倾斜（最大 6°，600ms，cubic-bezier(0.4,0,0.2,1)），鼠标离开后平滑回正；单张卡片 hover 时沿 Z 轴浮出 12px，600ms。
- 按钮 hover 时透明度 0.85，400ms；无缩放、无弹跳。
- 次要层：每张卡片后方一道细光晕，幅度为主卡片的 30%，比主卡片晚 100ms 出现。
- 环境层：背景有极轻微的光晕呼吸（透明度 0.97–1 循环，3000ms），从不抢注意力。
- 每时每刻只有一个主角，其他元素暗到 40–60%。

技术约束：单文件输出，不引入第三方框架和图片，不使用内联事件；3D 只用 CSS transform（perspective / translateZ / rotateX / rotateY），不引入 WebGL 库。
响应式：390px、768px、1440px 无横向滚动，正文不小于 16px；窄屏时三张卡片改为纵向排列，纵深改为上下错开。

验收：代码后列出标题层级、键盘、窄屏和空状态检查结果；动效检查：缓动是不是 (0.4,0,0.2,1)、超调是不是 0%、时长在 400–700ms 内、纵深三层是否分明、倾斜角度不超过 6°、次要层和环境层是否齐全；无法判断的项目标注“需浏览器实测”。
```
