# Cube 3D — 可旋转 3D 立方体产品展示

人格：Playful｜情绪：喜悦｜适用：儿童产品、玩具、轻松产品展示

## 提示词（复制给 AI）

```
你是一名重视可访问性的前端工程师。请用原生 HTML、CSS 和 JavaScript 制作一个中文儿童积木玩具的响应式产品展示页，核心是一个可旋转的 3D 立方体。

目标：让第一次访问的家长和孩子在 3 秒内被立方体吸引，并找到“看看玩法”操作。

页面结构：顶部导航（Logo + 3 个链接）、首屏（主标题、副标题、一个主按钮）、立方体展示区（一个 CSS 3D 立方体，6 个面各一种颜色 + 一个表情或图案 + 左右切换箭头）、底部一行 3 个卖点。

内容要求：主标题不超过 10 个字；副标题一句话说清价值；不要编造用户数量、奖项；未知数据用明确占位。

视觉规范：浅色背景，单一亮色强调（橙色或绿色）；标题大字重，圆角 16px；最大内容宽度 1200px；无渐变和装饰性光晕。
人格 Playful，全篇只用一种人格。标志性缓动 ease-out-back，超调 10–20%。
主情绪喜悦：入场用弹跳、弧线路径，向上；旋转用 ease-out-back，200–400ms。
立方体：6 个面，边长 220px，父容器 perspective 1000px；每个面一种亮色 + 一个大表情符号；立方体下方有一圈椭圆阴影。

交互要求：
- 入场：立方体从缩放 0.9 + 上移 24px 弹入（300ms，ease-out-back，超调 15%），标题比立方体早 80ms。
- 拖拽旋转：按住立方体左右拖，立方体跟手绕 Y 轴旋转；松手后 ease-out-back 回弹到最近的 90° 整面（300ms，超调 15%）。
- 箭头切换：点左/右箭头，立方体绕 Y 轴转 90° 到上一面/下一面（300ms，ease-out-back）。
- 自动慢转：无操作 5 秒后，立方体每 6 秒自动转 90°（匀速转动，转圈可用线性缓动）；用户一碰就停。
- 按钮 hover 时放大 1.05，300ms ease-out-back；点击时缩小 0.97。
- 次要层：立方体下方的阴影随旋转缩放（幅度为主体的 30–50%），比主层晚 50ms。
- 环境层：背景漂浮 3 个小图形（星星/圆点），极轻微上下浮动，从不抢注意力。
- 每时每刻只有一个主角，其他元素暗到 40–60%。

技术约束：单文件输出，不引入第三方框架和图片，不使用内联事件；3D 只用 CSS transform（perspective / rotateX / rotateY / translateZ），不引入 WebGL 库。
响应式：390px、768px、1440px 无横向滚动，正文不小于 16px；窄屏时立方体边长改为 160px。

验收：代码后列出标题层级、键盘、窄屏和空状态检查结果；动效检查：缓动是不是 ease-out-back、超调在 10–20% 内、松手回弹是否对准 90° 整面、单次运动不超 1/3、次要层和环境层是否齐全；无法判断的项目标注“需浏览器实测”。
```
